# Sol
📈 Solana Arbitrage Bot
A fully automated, FastAPI-based arbitrage bot that scans Solana DEX price quotes in real time (via Jupiter Aggregator), identifies profitable spreads, and executes trades using a Solana wallet.

✅ Features
🧠 Real-time arbitrage loop with spread calculations

🔐 Wallet auto-generation on first run (wallet.json)

🔄 Auto-trade execution for spreads above 0.5%

🌐 FastAPI backend with / and /execute-trade endpoints

🪙 Solana RPC Integration via solana-py

🧩 Ready for deployment on Render.com
